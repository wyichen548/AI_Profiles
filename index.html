商業電商 / POS RWD 響應式

楊老大飲料店

線上點餐 & 客製化菜單系統

作品簡介

專為手搖茶飲店打造的完整響應式線上點餐平台。顧客可自由客製冰塊、甜度與加料選項，即時計算消費金額並支援購物車管理。送出後自動整合遠端試算表進行訂單歸檔，大幅提升小型店家接單與結帳效率。

使用 API 與技術

Google Apps Script (GAS) API Fetch API (非同步無阻跨域) DOM Event Manipulation API

應用場景

  • 手搖茶飲店、咖啡輕食店免安裝式顧客自助點餐
  • 辦公室同仁團購訂單快速統計與無紙化總整
  • 市集快閃攤位或活動外送訂購即時彙整
打開作品 (開啟點餐系統)
桌面實用工具 全螢幕互動

明星簡潔時鐘桌布

沉浸式動態時鐘與輪播桌布

作品簡介

打造極簡沉浸式數位時鐘與動態桌面展示小工具。支援12/24小時制切換、即時秒數與完整日期星期資訊。內建高畫質桌布自動輪播、模糊度及透明遮罩自訂調節功能，兼具實用時鐘與優雅螢幕保護桌布。

使用 API 與技術

JavaScript Date & Timing API Fetch API (動態讀取外部圖庫 CSV) CSS Backdrop Filter & Keyboard Event API

應用場景

  • 辦公室第二螢幕、書桌平板常駐翻頁式時鐘相框
  • 簡報演講中場休息投影或展覽迎賓動態視覺
  • 沉浸式個人專注工作番茄鐘輔助計時介面
打開作品 (開啟時鐘桌布)
氣象儀表板 玻璃擬態

台灣即時天氣氣象站

全台22縣市精準氣候預報

作品簡介

採用現代玻璃擬態風格的全台即時天氣儀表板。使用者可快速切換22個縣市，即時掌握最新溫度、體感、濕度、紫外線與降雨機率，並呈現未來多日氣溫走勢圖，讓每日出門穿著與戶外行程規劃變得一目了然。

使用 API 與技術

Open-Meteo Weather API (全球即時預報) Fetch API & Async/Await 解析 台灣全縣市經緯座標映射演算法

應用場景

  • 每日早晨上班、上課前穿著搭配與雨具攜帶查詢
  • 週末跨縣市家庭出遊、露營或登山即時天候掌握
  • 外送員、業務通勤外勤即時降雨與溫差避險參考
打開作品 (開啟天氣氣象站)
